# I remember you!

[English](README.md) · **Русский** · [Список изменений](CHANGELOG.md)

Аддон для The Elder Scrolls Online, который помнит **игроков**, а не только
имена.

В ESO игрок может сменить свой `@account`, и все аддоны, список друзей и ссылки
в чате внезапно показывают незнакомца. **I remember you!** сохраняет того, кого
вы уже знаете: он связывает старый и новый `@account` в одну сущность, показывает
стабильное имя в рамке цели и в чате и сообщает, когда ID аккаунта меняется.

Аддон не считает убийства и никогда не пишет в чат за других игроков. Всё, что
он печатает, видно только вам.

---

## Что видно в игре

* **Рамка цели** — когда вы наводите прицел на игрока, в строке имени
  показывается привычное вам имя вместо текущего `@account`. Значок сложности и
  маркер цели остаются на месте. Строка под именем собирается заново как
  `имя персонажа + титул`.
* **Иконки игроков** — одна иконка на игрока из библиотеки, поставляемой с
  аддоном (свой набор плюс лорный пак из игровой графики ESO): в рамке цели,
  списке друзей, составе гильдии, списке игнорирования и
  окне списка. Если установлен **OdySupportIcons**, та же иконка висит над
  участниками группы и появляется в списке группы Поиска группы; с ним или без
  него иконка участников группы также видна на мировой карте и на миникартах на
  игровом менеджере пинов (Votan's Minimap). Персонажам из игрового списка
  игнорирования можно автоматически ставить иконку-метку (по умолчанию — петух);
  иконка, заданная вручную, всегда важнее.
* **Метка над прицелом** — необязательная экранная иконка рядом с перекрестием:
  иконку цели видно, не глядя в рамку цели. По умолчанию выключена; её можно
  перетащить левой кнопкой мыши куда удобно и закрепить. У метки свой размер
  (до 128 px), и её можно ограничить враждебными целями, живыми или только
  PvP-зонами.
* **Чат** — к ссылкам на игроков добавляется суффикс: `@НовоеИмя (СтароеИмя)`.
  Сама ссылка не меняется, по ней по-прежнему можно кликнуть.
* **Друзья, состав гильдии и список группы** — к имени аккаунта в социальных
  списках дописывается запомненное имя: `@НовоеИмя (СтароеИмя)`, а к имени
  персонажа в списке группы в Поиске группы — тоже запомненное имя. Само игровое
  имя не заменяется, поэтому список по-прежнему сортируется и ищется по
  настоящему имени.
* **Kill feed в PvP** — сообщения об убийствах дополняются запомненными именами
  обеих сторон.
* **Уведомления** — когда известный игрок появляется под новым `@account`, в чат
  приходит одна строка: `Смена ID: @Старый -> @Новый это Вася (#12, подтверждено)`.

Переименовывается только рамка цели под прицелом. Рамки группы, неймплейты и
все прочие окна остаются с именами от игры.

## Установка

1. Скопируйте папку `IRememberYou` в
   `Документы/Elder Scrolls Online/live/AddOns/`.
   В итоге должно получиться `.../AddOns/IRememberYou/IRememberYou.txt`.
2. Запустите игру, откройте **Настройки → Аддоны** и включите
   **I remember you!**.
3. Введите `/reloadui`.

Обязательных зависимостей нет. **LibAddonMenu-2.0** добавляет панель настроек;
без него всё работает через слэш-команды. **OdySupportIcons** необязателен:
только он рисует 3D-иконки над участниками группы и иконку игрока в списке
группы Поиска группы; собственные 2D-иконки аддона, пины на карте и подписи с
запомненным именем работают без него.

## Как открыть список игроков

В списке видно и можно править всё, что аддон запомнил:

* **Настройки → Аддоны → I remember you! → «Открыть список игроков»**;
* или назначьте клавишу: **Управление → Общие → I remember you! → «Открыть
  список игроков»** (по умолчанию не назначена);
* или введите **`/pa browse`**.

В списке можно:

* искать по имени, `@account` или имени персонажа;
* **менять размер окна**, потянув за правый нижний угол: список показывает
  столько строк, сколько помещается, так что в высоком окне больше игроков на
  странице;
* щёлкнуть по игроку и открыть **панель подробностей**: все запомненные
  `@account` с временем последней встречи и все персонажи с альянсом и уровнем;
* переименовать игрока как угодно (Enter или кнопка);
* вернуть имя обратно — к первому запомненному `@account`;
* объединить две строки, если это на самом деле один человек (выберите первую,
  выберите вторую, нажмите **«Объединить»**);
* отменить последнее объединение;
* подтвердить или отклонить вероятные связи на вкладке **«Ожидают»**;
* забыть игроков, у которых истёк срок хранения.

Панель подробностей одна: щелчок по другому игроку заменяет её содержимое,
переключение вкладки или закрытие списка её закрывает. Прокручивается колесом
мыши.

Окно закрывается по `Escape`, его положение **и размер** запоминаются.

## Команды

Все команды начинаются с `/pa` (есть псевдоним `/iry`).

| Команда | Что делает |
| --- | --- |
| `/pa browse` | открыть список игроков |
| `/pa who [имя\|id]` | подробности об одном игроке (без аргумента — текущая цель) |
| `/pa list [n]` | список известных игроков |
| `/pa count` | сколько игроков запомнено |
| `/pa rename <id> <имя>` | задать своё отображаемое имя |
| `/pa reset <id>` | вернуться к первому `@account` |
| `/pa forget <id>` | удалить сущность игрока |
| `/pa merge <id> <id>` | объединить две сущности |
| `/pa undo <id>` | отменить объединение (id поглощённой сущности) |
| `/pa pending` | связи, ждущие подтверждения |
| `/pa yes [n]` / `/pa no [n]` | подтвердить / отклонить ожидающую связь |
| `/pa purge [дней] [подтверждаю]` | показать, кого забудет, а с `подтверждаю` — удалить |
| `/pa icons [on\|off]` | показать или скрыть все иконки игроков |
| `/pa icon <id> [путь\|clear]` | показать, задать или снять иконку игрока |
| `/pa marker [test]` | отчёт о метке прицела или тестовая картинка |
| `/pa debug on\|off` | отладочный вывод в чат |

ID показываются как `#12`; везде, где ожидается id, подойдут `12`, `#12`,
`@Account` и имя персонажа.

## Откуда берутся имена

Аддон узнаёт только то, что игра ему показывает или сообщает:

* цель под прицелом — `@account` и имя персонажа вместе (основной источник);
* группа, список друзей, состав гильдии и kill feed в PvP — как дополнительные
  источники;
* уведомления друзей и группы, когда игра сообщает о смене аккаунта.

**Новый `@account` у уже известного персонажа** считается *вероятной* связью: он
попадает на вкладку **«Ожидают»** и ждёт `/pa yes`, чтобы незнакомец со знакомым
именем персонажа не мог молча забрать чужую запись. Это поведение меняется
опцией «Принимать вероятные связи без вопросов».

## Настройки

**Настройки → Аддоны → I remember you!** (нужен LibAddonMenu-2.0)

* **Рамка цели** — заменять имя, заменять подпись, скрывать подпись.
* **Чат** — добавлять запомненное имя к ссылкам на игроков, помечать убийства в
  PvP и дописывать запомненное имя в списке друзей, составе гильдии и списке
  группы в Поиске группы.
* **Сбор данных** — какие источники могут чему-то научить аддон, можно ли
  записывать вас самих (по умолчанию нет), плюс интервал опроса цели (по
  умолчанию 1000 мс).
* **Связывание** — насколько подробно сообщать о смене ID, принимать ли
  вероятные связи автоматически, объединять ли конфликты автоматически.
* **Иконки игроков** — главный выключатель, размер иконок в UI, иконки на
  мировой карте и миникарте, необязательная
  метка над прицелом (свой размер, перетаскивание с закреплением, фильтры
  «трупы / враждебные / PvP»), пометка игнорируемых и её иконка. 3D-часть и
  иконку в списке группы рисует OdySupportIcons, если он установлен.
* **Обслуживание** — срок хранения (`0` = не забывать никогда), кнопка «Забыть
  старых игроков сейчас» (только показывает, кого удалит, пока вы не подтвердите
  словом в чате) и отладочный вывод.

По умолчанию все функции отображения включены, ничего не принимается молча и
ничего не удаляется само.

## Ограничения

* Аддоны ESO не могут читать или писать файлы. Импорта и экспорта нет; база —
  это SavedVariable `IRememberYouSV`, общая на весь аккаунт.
* Игрока можно узнать, только если игра хотя бы раз сообщила аддону его аккаунт
  и персонажа одновременно.
* Друзья из списка друзей добавляются даже оффлайн; показывается последний
  известный персонаж. Если данных о персонаже нет, друг сохраняется только по
  имени аккаунта.
* Состав гильдии игра подгружает лениво, поэтому данные гильдии появляются через
  несколько секунд после входа.
* Переименование персонажа не переименовывает игрока: у сущности остаётся
  стабильное имя и появляется ещё один псевдоним персонажа.
* В списке друзей, составе гильдии и списке группы запомненное имя делит колонку
  с игровым именем: длинное сокращается многоточием. Размеры строк не меняются,
  поэтому колонка «Локация» не сдвигается.
* 3D-иконки над участниками группы и иконку игрока в списке группы Поиска
  группы рисует **OdySupportIcons**; без него подпись с запомненным именем и все
  2D-иконки самого аддона продолжают работать. Иконки в окне группы у OSI
  включены по умолчанию. Своя библиотека — 81 иконка в `icons/base` — лежит в
  аддоне, а лорный пак из 82 текстур берётся из игровой графики ESO и потому
  ничего не добавляет к размеру загрузки. Оба пака перечислены в
  `core/iconpacks.lua`, выбираются в панели деталей или через `/pa icon`, а
  окно выбора листает страницы.
* Иконки на карте доступны только участникам группы: пинов для остальных
  игроков ESO не создаёт. Они видны на мировой карте и на миникартах на игровом
  менеджере пинов (Votan's Minimap); миникарты со своей системой пинов
  (Fyrakin's) не покрываются. OdySupportIcons для этого не нужен.
* Метка над прицелом — экранная накладка, а не 3D-иконка: она не следует за
  дистанцией до цели. Близкая цель выглядит как картинка на уровне груди,
  далёкая — как картинка над головой. Поставьте её туда, где вам важна
  дистанция: функции расстояния до юнита в ESO нет, автоматически это не
  посчитать.
* Системные сообщения о входе игрока в зону и выходе из неё игра строит без
  ссылок на игрока, поэтому в них остаётся исходный `@account` без приписки с
  запомненным именем. Kill feed в PvP дополняется.

## Если что-то не работает

* **Рамка цели не изменилась** — проверьте, что включено «Заменять имя цели» и
  что аддон включён после последнего патча.
* **«Версия API … вне списка поддерживаемых»** — игра обновилась. Аддон всё равно
  попробует работать; поищите свежий релиз.
* **Нет панели настроек** — не установлен LibAddonMenu-2.0. Пользуйтесь
  слэш-командами.
* **В списке группы нет иконки игрока** — её рисует OdySupportIcons, а не этот
  аддон. Подпись с запомненным именем работает и без него; проверьте настройки
  иконок окна группы в OSI.
* **Незнакомец показывается под именем друга** — откройте список, выберите
  неверную строку и нажмите **«Сброс»**, либо отмените объединение через
  `/pa undo`.
* **Вы сами оказались в списке** — начиная с 0.2.1 аддон вас игнорирует. Старая
  строка сама не удаляется: уберите её командой `/pa forget <id>`.
* **Метка над прицелом висит рядом с головой** — это фиксированная экранная
  картинка, а не 3D-иконка. Поставьте галочку «Переместить метку», перетащите
  её туда, где ожидаете на своей обычной дистанции боя, и снимите галочку.
* **Метки нет, пока она разблокирована** — проверьте главный выключатель иконок:
  режим перетаскивания игнорирует фильтры и скрытый прицел, но не `showIcons`.
* **Имена в kill feed не помечаются** — проверьте «Помечать сообщения о
  убийствах в PvP» в секции «Чат» и что игрок уже запомнен. Системные сообщения
  о входе/выходе не помечаются никогда: игра не даёт в них ссылку на игрока.

## Изменения

**0.5.1**
* шесть новых иконок в поставляемой библиотеке: `doge-smile`, `horse`,
  `imperial-soldier`, `risitas-form`, `templar` и `zmeigorinich` (81 иконка в
  `icons/base`);
* у доге и лошади вырезан фон, поэтому он прозрачный; остальные сохраняют
  прозрачность исходных PNG.

**0.5.0**
* иконки игроков на мировой карте и на миникартах на игровом менеджере пинов
  (Votan's Minimap); пины есть только у участников группы, поэтому покрыты
  только они;
* запомненное имя дописывается в списке группы Поиска группы после имени
  персонажа с номером; индекс группы и игровое имя остаются на месте;
* иконку игрока в списке группы рисует OdySupportIcons, если он установлен;
  без него работают подпись с запомненным именем, пины на карте и все 2D-иконки
  самого аддона;
* OdySupportIcons и LibAddonMenu-2.0 по-прежнему необязательны.

**0.4.0**
* одна иконка на игрока в рамке цели, списке друзей, составе гильдии, списке
  игнорирования и окне списка;
* иконки задаются вручную из панели подробностей или командой `/pa icon`, а все
  сразу отключаются через `/pa icons off` или настройки;
* персонажей из игрового списка игнорирования можно помечать отдельной иконкой;
* необязательная метка над прицелом, отключается тем же мастер-выключателем:
  свой размер, перетаскивание с закреплением и фильтры «трупы / враждебные /
  только PvP»; у участников группы остаётся только 3D-иконка OSI, без второй
  экранной копии;
* kill feed в PvP помечает оба имени, даже если чатовый аддон перерегистрировал
  форматтер или строка раскрашена цветом команды поля сражений;
* удаление старых игроков требует подтверждения словом
  (`/pa purge <дней> подтверждаю`), а кнопки в настройках и браузере только
  показывают, кого удалят;
* 3D-иконки над группой через **OdySupportIcons**, при этом его собственные
  настройки и сохранённые иконки не теряются. Игрокам вне группы иконка достаётся
  только в интерфейсе: ESO не отдаёт их позицию в мире, поэтому 3D-иконку над ними
  не может нарисовать ни один аддон.

**0.3.0**
* список игроков можно растягивать; число строк зависит от высоты окна;
* список открывается на переднем плане, а не за другими окнами;
* щелчок по игроку открывает одну переиспользуемую панель подробностей со всеми
  аккаунтами и всеми персонажами, включая альянс и уровень;
* альянс каждого персонажа сохраняется и обновляется по новым наблюдениям;
* запомненное имя дописывается в списке друзей и составе гильдии (новая
  настройка, включена по умолчанию).

**0.2.1**
* вы сами больше не записываетесь (переключатель в панели настроек);
* друзья запоминаются даже оффлайн;
* `/pa forget <id>` удаляет одного игрока.

**0.2.0**
* список игроков (поиск, переименование, объединение, отмена, ожидающие связи,
  чистка);
* панель настроек (LibAddonMenu-2.0);
* горячая клавиша для открытия списка;
* срок хранения по умолчанию выключен;
* список закрывается по Escape.

**0.1.0**
* первая рабочая версия: хранилище сущностей, рамка цели, ссылки в чате,
  kill feed, определение переименований, уведомления, слэш-команды.

```
  lang/                   строки на английском и русском
```

Русская локализация включается автоматически: аддон берёт `lang/ru.lua`, когда
язык клиента — русский.
